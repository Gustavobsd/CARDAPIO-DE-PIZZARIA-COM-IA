# 🍕 Cardápio de Pizzaria com IA

Um projeto inovador que utiliza **Inteligência Artificial** para gerenciar e otimizar o cardápio de uma pizzaria, com recomendações inteligentes e análise de dados.

## ✨ Funcionalidades

- 🤖 **Recomendações com IA** - Sistema inteligente para sugerir pizzas baseado em preferências
- 📊 **Análise de Dados** - Estatísticas e insights sobre os pizzas mais populares
- 🍴 **Gerenciamento de Cardápio** - Fácil atualização de pizzas, ingredientes e preços
- 📈 **Otimização** - Sugestões de pricing e combinações mais lucrativas

## 🚀 Como Começar

### Pré-requisitos
- Python 3.8+
- Jupyter Notebook
- pip

### Instalação

```bash
# Clone o repositório
git clone https://github.com/Gustavobsd/CARDAPIO-DE-PIZZARIA-COM-IA.git

# Entre no diretório
cd CARDAPIO-DE-PIZZARIA-COM-IA

# Instale as dependências
pip install -r requirements.txt

# Execute o Jupyter Notebook
jupyter notebook
```
