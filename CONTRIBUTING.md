# 🤝 Contribuindo para o Projeto

Obrigado por se interessar em contribuir! Este documento fornece diretrizes e instruções para contribuir ao projeto.

## Como Contribuir

### 1. Fork o Repositório
- Clique no botão "Fork" no canto superior direito

### 2. Clone seu Fork
```bash
git clone https://github.com/seu-usuario/CARDAPIO-DE-PIZZARIA-COM-IA.git
cd CARDAPIO-DE-PIZZARIA-COM-IA
```

### 3. Crie uma Branch
```bash
git checkout -b feature/sua-feature
# ou
git checkout -b fix/seu-bug-fix
```

### 4. Faça suas Mudanças
- Sempre trabalhe em uma branch separada
- Mantenha commits pequenos e descritivos
- Siga as convenções de código do projeto

### 5. Commit e Push
```bash
git add .
git commit -m "tipo: descrição clara da mudança"
git push origin feature/sua-feature
```

### 6. Abra um Pull Request
- Descreva claramente as mudanças
- Referencie issues relacionadas (se houver)
- Aguarde a revisão

## 📋 Convenções de Commits

Usamos a convenção Conventional Commits:

- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `docs:` Mudanças em documentação
- `style:` Formatação, sem mudanças de lógica
- `refactor:` Refatoração de código
- `test:` Adição ou modificação de testes
- `chore:` Mudanças em build, deps, etc.

## 🎯 Diretrizes

- Código legível e bem comentado
- Adicione testes para novas funcionalidades
- Atualize a documentação
- Respeite o código existente
- Seja educado e construtivo
